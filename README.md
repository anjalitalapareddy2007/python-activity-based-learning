# Python Activity-Based Learning – 10 Case Studies

## 📌 Project Description

This project contains Python solutions for the first 10 case studies given in the Python Activity-Based Learning assignment. The programs solve real-world problems using basic Python programming concepts.

## 🎯 Objectives

- Understand problem-solving using Python.
- Develop algorithms and pseudocode.
- Use conditional statements and loops.
- Work with variables, operators, lists, and tuples.
- Solve practical problems using simple Python programs.

## 📚 Topics Covered

1. **University Scholarship Allocation** – Checks student eligibility and ranks applicants.
2. **Progressive Electricity Billing** – Calculates electricity bills using consumption slabs.
3. **Hospital Billing and Patient Classification** – Calculates hospital bills and concessions.
4. **Employee Payroll and Deduction Analysis** – Calculates gross salary, deductions, and net salary.
5. **Multi-Plan Telecommunications Cost Optimization** – Compares mobile plans and selects a suitable plan.
6. **Railway Fare and Reservation Calculator** – Calculates passenger fares and cancellation charges.
7. **Retail Billing with Multiple Discount Rules** – Calculates product prices, discounts, taxes, and final bills.
8. **Manufacturing Cost and Profitability Analysis** – Calculates production costs, revenue, and profit.
9. **Multi-Currency Travel Budget Analysis** – Converts travel expenses and checks the budget.
10. **Campus Event Financial Planning** – Calculates event expenses, sponsorship, and break-even registrations.

## ▶️ How to Run the Programs

1. Install Python 3 on your computer.
2. Download or clone this repository.
3. Open the project folder in Python IDLE or VS Code.
4. Open the required `.py` file.
5. Run the program.
6. Enter the requested input values.
7. Check the output displayed on the screen.

Example:

```bash
python case_study_01_scholarship.py
```
